# Password Generator 🔐

A responsive Password Generator application built using React, Vite, and Tailwind CSS. This app allows users to generate secure random passwords with customizable options such as password length, numbers, and special characters.

## Preview

Generate strong passwords instantly with customizable settings and one-click copy functionality.

## Features ✨

* Random password generation
* Adjustable password length slider
* Option to include numbers
* Option to include special characters
* Copy password to clipboard
* Responsive and clean UI
* Built using React Hooks

## Tech Stack 🚀

* React.js
* Vite
* Tailwind CSS
* JavaScript (ES6+)
* HTML5
* CSS3

## Installation & Setup

Clone the repository:

```bash
git clone <repository-url>
```

Move into the project directory:

```bash
cd 05passGenerator
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
